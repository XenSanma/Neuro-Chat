# Neuro-Chat
A sleek, lightweight browser-based AI chat interface powered by the Gemini API. Engineered to maintain fast response times and handle heavy traffic without lag, this interface uses precise system prompting to replicate Claude's highly analytical, step-by-step reasoning. It is exceptionally well-suited for complex logic, coding, and advanced mathematics.

##  Features

* **Zero Installation:** Runs entirely in your browser via a single HTML/JavaScript setup.
* **Smart Memory:** Asks for your Gemini API key on the first launch and securely saves it locally in your browser's memory (`localStorage`). You never have to re-enter it unless you clear your cache.
* **Claude-Like Logic:** Deeply prompted to provide rigorous, thoughtful, and fluff-free answers.
* **Math & Code Optimized:** Renders beautifully formatted equations using LaTeX notation and clean code blocks.

---

## How to Use

1. **Download the Project:** Download or clone this repository to your local machine.
2. **Open the App:** Simply double-click the `NeuralChat-v4.html` file to open it in any modern web browser (Chrome, Firefox, Edge, Safari).
3. **Enter Your Key:** The interface will prompt you to enter your Gemini API key. Paste your key in, click save, and start chatting!

---

## How to Get Your Gemini API Key

To use this interface, you need a free or paid API key from Google:

1. Visit **[Google AI Studio](https://aistudio.google.com/)**.
2. Sign in using your standard Google account.
3. Click the **"Get API key"** button located in the top-left menu.
4. Click **"Create API key"**, choose or create a project, and copy your newly generated key.
5. Paste this key directly into the prompt box when you open the HTML page.

> 🔒 **Security Note:** Your API key is stored strictly within your browser's local storage. It is sent directly to Google's API endpoints and is never transmitted to any third-party servers or me.
